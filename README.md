# Doutor Consignado — Consórcios e Seguro Auto

Página estática responsiva, com identidade branca e laranja e ilustração vetorial própria. Inspirada na organização comercial da referência fornecida, sem copiar marca, imagens ou ofertas da Porto.

## Abrir no computador
Extraia o ZIP e abra `index.html` no navegador. Não há instalação de dependências. Mantenha os quatro arquivos de implementação juntos.

## Colocar no GitHub
1. Abra https://github.com/anacaroline0298/central-doutor-consignado/upload/main
2. Arraste os arquivos EXTRAÍDOS desta pasta (não envie somente o ZIP).
3. Confirme em Commit changes. O README existente pode ser substituído por este.
4. Volte ao Codex e peça: “Leia o README e verifique a página estática. Não precisa instalar dependências. Use python3 -m http.server 8000 para visualizar.”

## Arquivos
- index.html: estrutura e textos.
- styles.css: visual e adaptação para celular.
- config.js: número de WhatsApp.
- app.js: seleção de produto, formulário, links e aviso de privacidade.

## Funcionamento real
O formulário valida nome, cidade e consentimento; seguro exige veículo. Abre o WhatsApp com mensagem pronta. O visitante precisa enviar a mensagem. Não há envio por servidor, armazenamento de leads, integração com seguradora, cálculo de preço, venda ou pagamento automático.

## Antes da divulgação comercial
Confirme o número 0800 878 7026 no WhatsApp. Ajuste config.js se necessário. Acrescente razão social, CNPJ e identificação dos fornecedores/intermediários efetivamente responsáveis, conforme sua operação. Revise o aviso de privacidade de acordo com o atendimento real. Não foram presumidos credenciamentos, seguradoras parceiras, preços, taxas ou promessas de contemplação.

## Publicar em sua hospedagem
Envie index.html, styles.css, config.js e app.js para a mesma pasta pública da hospedagem. Este pacote não altera o site atual nem configura domínio automaticamente.

## Verificação
JavaScript verificado com node --check. Referências locais e estrutura HTML conferidas. Teste o envio real no celular e no computador antes de divulgar, especialmente porque números 0800 dependem da disponibilidade da conta no WhatsApp.
